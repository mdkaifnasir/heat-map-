# Project Roadmap & Issues

This document tracks potential features and enhancements for the Maharashtra MLA Heatmap. These can be tracked as Issues in the GitHub repository.

## ✅ Completed Features
- **[x] Interactive Heatmap**: Core density visualization.
- **[x] Search & Party Filter**: Real-time filtering by constituency and party.
- **[x] Professional Intelligence Dashboard**: 
  - **Party-Coded Markers**: Brand colors for all parties.
  - **Geospatial Control**: Satellite vs. Light view toggle.
  - **Active Intelligence**: Click charts to filter + CSV export.
  - **Mobile Responsive**: Flawless usage on phones.
